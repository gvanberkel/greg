### [flutter_slick](https://pub.dev/packages/flutter_slick) (2021 to present day)
Flutter slick is a Flutter package that exposes an easy to use MVVM framework, permission management and navigation system for easy app development. It is actively used on several large scale projects across multiple teams and companies.

### slickjs (2012)
Slickjs is a Single Page App framework built to support both legacy devices and modern web browsers with a single codebase using Knockout and Jquery. It is used on two large scale solutions.

### Web Forms (.NET Framework) SPA (2008)
Web Forms developer patterns and Single page app framework. While legacy it is still actively used and maintained on 3 large products.

### Cota (2005)
Cota is an Object Relational Mapping tool for MS SQL and .NET. It forms the ORM foundation of many solutions built in the mid 2000s.
