# Web Forms SPA

*What is it?:* ***Web Forms developer patterns and Single page app framework***  
  
Using Microsoft Web Forms and AJAX Control Toolkit I put together some base classes and patterns for the TFN and Providence dev teams. While legacy it is still actively used and maintained on 3 large products.

The main highlights 
- Permissions and Security framework
- Single Page App support via a screen AJAX Control control bootstrapper.
- Generic screen and feature based permissions system.
